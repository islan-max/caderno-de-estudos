## Aula Teórica Completa

**Forma geral.** f(x) = ax² + bx + c. Os três coeficientes têm papel fixo: a controla a abertura e a orientação da parábola (nunca pode ser zero, senão vira função do 1º grau); b interfere na posição horizontal da parábola; c é o valor de f(0), ou seja, onde a parábola corta o eixo y.

**Concavidade.** Se a > 0, a parábola tem concavidade voltada para cima (formato de "sorriso"), e existe um ponto de mínimo. Se a &lt; 0, a concavidade é voltada para baixo (formato de "monte"), e existe um ponto de máximo. Isso é decidido olhando só o sinal de a: é a primeira coisa a checar em qualquer questão.

**Raízes (zeros da função).** São os valores de x para os quais f(x) = 0, isto é, onde a parábola cruza o eixo x. Calculam-se pela fórmula de Bhaskara:

x = (−b ± √Δ) / (2a)

onde x é a raiz procurada, b e a são os coeficientes da função, e Δ (delta) é o discriminante, calculado por:

Δ = b² − 4ac

sendo b e a e c os três coeficientes da função.

**O que Δ revela.** Se Δ > 0, existem duas raízes reais diferentes (a parábola corta o eixo x em dois pontos). Se Δ = 0, existe uma raiz real dupla (a parábola toca o eixo x em um único ponto: é exatamente o vértice). Se Δ &lt; 0, não existem raízes reais (a parábola não toca o eixo x). Essa última situação é chave em muitas questões: "vértice sobre o eixo x" é sinônimo direto de Δ = 0.

**Vértice da parábola.** É o ponto de máximo ou mínimo da função. Suas coordenadas são:

xv = −b / (2a)

yv = −Δ / (4a)

onde xv é a coordenada horizontal do vértice, yv é a coordenada vertical (o valor máximo ou mínimo da função), e a, b, Δ são os mesmos termos já definidos. Uma propriedade importante: xv é sempre a média aritmética das duas raízes, quando elas existem, isso evita ter que usar a fórmula quando você já tem as raízes.

**Forma fatorada.** Quando as raízes x₁ e x₂ são conhecidas, a função pode ser escrita como:

f(x) = a(x − x₁)(x − x₂)

onde a é o coeficiente do termo x², e x₁, x₂ são as raízes. Essa forma é extremamente útil em questões de modelagem: se o enunciado te dá pontos onde a parábola "toca o chão", já se tem x₁ e x₂ de graça, e só falta descobrir a.

**Montando a função a partir de um problema real.** Esse é o tipo de questão mais comum no ENEM. O procedimento padrão: identificar os pontos conhecidos (raízes, vértice, ou pontos quaisquer do gráfico), escolher a forma mais conveniente (geral, fatorada, ou pela fórmula do vértice), substituir os pontos e resolver o sistema para achar os coeficientes.

**Pegadinhas do INEP:**
Confundir "vértice" com "raiz": o vértice é o ponto extremo, a raiz é onde f(x) = 0; eles só coincidem quando Δ = 0.
Ignorar o domínio do problema: em contextos reais (tempo, quantidade de pessoas), x geralmente só pode ser um número natural ou estar num intervalo, e a resposta "matemática" pode não fazer sentido físico (ex: tempo negativo).
Trocar concavidade: esquecer que a &lt; 0 dá máximo e a > 0 dá mínimo é um erro clássico sob pressão de tempo.
Calcular raiz quando a pergunta pede o vértice (ou vice-versa): isso aparece com frequência disfarçado em textos longos sobre epidemias, lucro, trajetórias.

## Tópicos-Chave para Revisão

<div className="topico">

Toda função quadrática tem a forma f(x) = ax² + bx + c, com a ≠ 0. O sinal de **a** define a concavidade: a > 0 é mínimo (parábola para cima), a &lt; 0 é máximo (parábola para baixo). **c** é sempre o valor onde a parábola corta o eixo y.

As raízes são os pontos onde a parábola cruza o eixo x, calculadas por x = (−b ± √Δ) / (2a), com Δ = b² − 4ac. O sinal de Δ determina quantas raízes reais existem: Δ > 0 duas raízes, Δ = 0 uma raiz (vértice sobre o eixo x), Δ &lt; 0 nenhuma raiz real.

O vértice é o ponto de máximo ou mínimo da parábola, com xv = −b/(2a) e yv = −Δ/(4a). O xv também é a média das duas raízes: atalho útil quando as raízes já são conhecidas.

A forma fatorada f(x) = a(x − x₁)(x − x₂) é a ferramenta certa quando o problema fornece diretamente os pontos onde a função vale zero, evitando montar sistemas maiores que o necessário.

Em problemas de modelagem (trajetórias, lucro, epidemias, arquitetura), o primeiro passo é sempre traduzir o texto em pontos do plano cartesiano (raízes, vértice, ou pontos quaisquer) e só depois escolher a fórmula. A segunda etapa crítica é identificar exatamente o que a pergunta quer: o valor de x (quando algo acontece) ou o valor de y (quanto vale nesse momento), são coisas diferentes e o ENEM explora essa confusão.
