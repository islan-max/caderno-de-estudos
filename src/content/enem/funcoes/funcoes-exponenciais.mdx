## Aula Teórica Completa

### Passo 1: Por que precisamos de uma função nova?

Você já estudou função linear (afim): y = ax + b. Nela, a cada passo, **soma-se** sempre a mesma quantidade. Exemplo: uma vela que perde 2 cm de altura a cada hora, sempre 2 cm, não importa a altura atual.

Mas existem fenômenos onde a variação não é uma soma fixa, e sim uma **multiplicação** fixa. Uma população de bactérias que dobra a cada hora: começa com 100, vira 200, depois 400, depois 800. Repare: o "quanto aumenta" muda a cada hora (100, depois 200, depois 400), mas o **fator multiplicativo** (×2) é sempre o mesmo. Isso é crescimento exponencial.

**A armadilha nº 1 do ENEM**: confundir "aumenta uma quantidade fixa" (afim) com "multiplica por um fator fixo" (exponencial). Sempre pergunte: o enunciado fala em *somar/subtrair* uma quantidade, ou em *dobrar/triplicar/reduzir à metade/aumentar X%*? Se for a segunda opção, é exponencial.

### Passo 2: A fórmula geral

f(x) = a · bˣ

Decompondo cada peça:
- **f(x)** = o valor da grandeza depois de x unidades de tempo (a "resposta" da função).
- **a** = o valor inicial, quando x = 0 (é o que você tinha no começo, antes de qualquer crescimento/decaimento).
- **b** = a base, chamada de **fator de crescimento** (se b > 1) ou **fator de decaimento** (se 0 &lt; b &lt; 1). É o número pelo qual você multiplica a cada unidade de tempo.
- **x** = a variável independente, geralmente o tempo, que fica no **expoente**.

Regra de ouro: **b > 1** → a função cresce. **0 &lt; b &lt; 1** → a função decresce (decai).

### Passo 3: Como descobrir "b" a partir de uma porcentagem

Esse é o formato favorito do ENEM: "aumento de 3% ao ano", "desvalorização de 10% ao ano", "reduz à metade a cada 6 horas".

- Se cresce X% ao período: b = 1 + (X/100). Exemplo: aumento de 3% → b = 1,03.
- Se decresce X% ao período: b = 1 − (X/100). Exemplo: desvalorização de 10% → b = 1 − 0,10 = 0,90.
- Se **dobra**: b = 2. Se **triplica**: b = 3. Se **reduz à metade**: b = 1/2 = 0,5.

### Passo 4: Meia-vida — um caso especialíssimo (e certo no ENEM)

Meia-vida é o tempo necessário para uma quantidade **cair pela metade**. Sempre que o enunciado der uma meia-vida "t½" e pedir o valor após um tempo T, o caminho mais rápido — e o que o ENEM espera — é:

1. Descobrir quantas meias-vidas cabem no tempo total: n = T / t½.
2. Dividir a quantidade inicial por 2, n vezes: quantidade final = inicial × (1/2)ⁿ.

**Armadilha nº 2 (fatal e recorrente)**: usar regra de três simples (linear) em problemas de meia-vida. Se algo perde metade em 8 dias, **não** significa que perde tudo em 16 dias — perde apenas 1/4 do que tinha, porque o decaimento é sempre "pela metade do que restou", não "pela metade do valor original a cada intervalo igual". Nunca aplique proporcionalidade direta aqui.

### Passo 5: A notação com "e" (número de Euler)

Às vezes a fórmula aparece como N(t) = N₀ · eᵏᵗ, onde "e" é a constante de Euler (≈ 2,718) e k é uma constante (positiva = crescimento, negativa = decaimento). Não se assuste: é a mesma lógica de f(x) = a·bˣ, só que a base é substituída por "e" elevado a uma constante. O ENEM costuma dar informação suficiente (como "triplicou em 1 hora") para você descobrir o valor de eᵏ substituindo diretamente na equação, sem precisar calcular k isoladamente — depois é só usar as propriedades de potência (eᵏᵗ = (eᵏ)ᵗ).

### Passo 6: Propriedades de potência que você vai usar o tempo todo

- aᵐ · aⁿ = aᵐ⁺ⁿ
- (aᵐ)ⁿ = aᵐ·ⁿ
- a⁻ⁿ = 1/aⁿ
- Se aᵐ = aⁿ, então m = n (quando a > 0 e a ≠ 1) — essa propriedade resolve equações exponenciais "escondendo" a variável no expoente igualando as bases.

### Padrões de armadilha do INEP nesse tópico

1. **Confundir crescimento linear com exponencial** (a armadilha mais comum, já citada).
2. **Aplicar regra de três em meia-vida/decaimento** (ignora que a base de comparação muda a cada intervalo).
3. **Esquecer o valor inicial "a"** quando o gráfico ou tabela não começa em x = 0, ou quando y(0) não é zero (como no problema do eucalipto, onde a muda já nasce com 0,5 m).
4. **Confundir a função exponencial com a logarítmica**: a exponencial responde "quanto tenho depois de um tempo X?"; a logarítmica (inversa) responde "quanto tempo leva para eu ter uma quantidade X?". O ENEM adora colocar uma alternativa logarítmica como distrator de uma pergunta puramente exponencial (e vice-versa).
5. **Em decaimento acumulado com doses repetidas** (bem comum em Química/Farmacologia), esquecer de somar o resíduo da dose anterior com a nova dose.

## Tópicos-Chave para Revisão

<div className="topico">

Função exponencial tem a forma **f(x) = a · bˣ**, onde a é o **valor inicial** (quando x=0), b é a **base** (fator de crescimento se b>1, fator de decaimento se 0&lt;b&lt;1), e x é o **expoente**, normalmente o tempo. A diferença crucial em relação à função afim é que aqui a variação é **multiplicativa** (multiplica-se por um fator fixo a cada intervalo), enquanto na afim a variação é **aditiva** (soma-se um valor fixo).

Para transformar uma **porcentagem de crescimento ou decaimento** em base b, use: cresce X% → b = 1 + X/100; decresce X% → b = 1 − X/100. Casos especiais: dobrar é b=2, triplicar é b=3, reduzir à metade é b=0,5.

**Meia-vida** é o tempo para uma grandeza cair pela metade. O cálculo correto é sempre por **meias-vidas sucessivas**: número de meias-vidas n = tempo total / meia-vida, e quantidade final = inicial × (1/2)ⁿ. Nunca use regra de três linear aqui — esse é o erro mais comum e mais punido pelo INEP.

A notação com o número de Euler, **N(t) = N₀·eᵏᵗ**, segue a mesma lógica: N₀ é o valor inicial, k é a constante de crescimento (positiva) ou decaimento (negativa). Informações do tipo "triplicou em 1 hora" servem para descobrir o valor de eᵏ diretamente, sem precisar isolar k.

As **propriedades de potência** (aᵐ·aⁿ=aᵐ⁺ⁿ, (aᵐ)ⁿ=aᵐⁿ, a⁻ⁿ=1/aⁿ, e a regra "bases iguais implicam expoentes iguais") são a ferramenta operacional para resolver qualquer equação exponencial que o ENEM apresentar.

O ENEM nunca cobra função exponencial isolada de contexto: ela sempre está embutida em situações de **modelagem real** — juros, radioatividade, medicamentos, população, depreciação de bens. Reconhecer o padrão verbal ("aumenta X% ao ano", "reduz à metade a cada Y horas", "triplica em Z horas") é o que te leva direto à base b correta.
