## Aula Teórica Completa

**O que é uma potência?**

Potência é uma forma resumida de escrever uma multiplicação repetida do mesmo número. Em vez de escrever 2 × 2 × 2 × 2, escrevemos 2⁴.

A estrutura é: aⁿ, onde a = base (o número que se repete), n = expoente (quantas vezes a base se multiplica por ela mesma).

Exemplo: 3⁴ = 3 × 3 × 3 × 3 = 81. Aqui, a base é 3 e o expoente é 4.

**Casos especiais de expoente**

Todo número elevado a 1 é ele mesmo: a¹ = a. Não muda nada, pois só há uma "cópia" da base.

Todo número (diferente de zero) elevado a 0 é igual a 1: a⁰ = 1. Isso parece estranho, mas faz sentido quando você entende as propriedades de divisão de potências (vamos ver adiante): é a única forma de manter a lógica consistente.

**Expoente negativo**

Quando o expoente é negativo, ele indica um inverso (uma fração). A regra é: a⁻ⁿ = 1/aⁿ.

Exemplo: 2⁻³ = 1/2³ = 1/8. O sinal negativo não torna o resultado negativo: ele "vira" o número em fração.

Pense assim: o expoente negativo é como um "aviso" de que o número deve ir para o denominador de uma fração, virando positivo lá.

**Propriedades operatórias das potências (o coração do assunto)**

Multiplicação de potências de mesma base: você conserva a base e soma os expoentes.
aᵐ × aⁿ = aᵐ⁺ⁿ. Exemplo: 2³ × 2² = 2⁵ = 32.

Por quê? Porque 2³ × 2² significa (2×2×2) × (2×2), que juntando tudo dá 5 multiplicações de 2.

Divisão de potências de mesma base: você conserva a base e subtrai os expoentes.
aᵐ ÷ aⁿ = aᵐ⁻ⁿ. Exemplo: 5⁶ ÷ 5² = 5⁴ = 625.

É por essa regra que aⁿ ÷ aⁿ = a⁰, e como qualquer número dividido por ele mesmo é 1, concluímos que a⁰ = 1.

Potência de potência: você conserva a base e multiplica os expoentes.
(aᵐ)ⁿ = aᵐˣⁿ. Exemplo: (2³)² = 2⁶ = 64.

Potência de um produto: o expoente "distribui" para cada fator.
(a × b)ⁿ = aⁿ × bⁿ. Exemplo: (2 × 3)² = 2² × 3² = 4 × 9 = 36 (confere: 6² = 36).

Potência de uma fração: o expoente distribui para numerador e denominador.
(a/b)ⁿ = aⁿ/bⁿ.

**Radiciação (raízes): a operação inversa da potenciação**

Se 3² = 9, então a raiz quadrada de 9 é 3. A raiz "desfaz" a potência.

Estrutura: ⁿ√a = b, onde n = índice (que raiz é, quadrada, cúbica etc.), a = radicando (o número de dentro), b = resultado.

Quando não há índice escrito, ele é 2 (raiz quadrada) por convenção: √9 significa ²√9.

**A ponte crucial: raiz é potência com expoente fracionário**

Este é o conceito que mais cai disfarçado no ENEM. Toda raiz pode ser reescrita como potência: ⁿ√aᵐ = a^(m/n).

Exemplo: ³√2² = 2^(2/3). Isso é poderoso porque permite aplicar TODAS as propriedades de potência (que você acabou de aprender) em expressões com raízes.

**Racionalização (tirar raiz do denominador)**

Por convenção matemática, não deixamos raiz no denominador de uma fração. Para eliminar, multiplicamos numerador e denominador pela mesma raiz.

Exemplo: 1/√2. Multiplicamos por √2/√2 (que vale 1, então não muda o valor): (1×√2)/(√2×√2) = √2/2.

**Pegadinhas clássicas do ENEM**

O ENEM adora misturar uma questão de contexto real (crescimento populacional, meia-vida radioativa, juros) com uma simplificação de potências que parece complicada, mas se resolve em 2-3 passos usando as propriedades.

Erro comum 1: achar que aᵐ × aⁿ = a^(m×n). Errado: na multiplicação de mesma base, os expoentes SOMAM, não multiplicam. Quem multiplica é a "potência de potência".

Erro comum 2: achar que (a+b)ⁿ = aⁿ+bⁿ. Isso é FALSO. A propriedade de distribuir o expoente só vale para multiplicação e divisão, nunca para soma ou subtração dentro dos parênteses.

Erro comum 3: confundir −a² com (−a)². Em −a², o expoente afeta só o "a", e o sinal de menos fica de fora: −3² = −9. Já em (−a)², o sinal entra na conta: (−3)² = 9. O ENEM explora isso com frequência.

Erro comum 4: em bases diferentes, não dá para somar/multiplicar expoentes diretamente. 2³ × 3² não simplifica pela regra de "mesma base": você precisa calcular cada potência separadamente (8 × 9 = 72), a menos que consiga transformar as bases (ex: 4ˣ = (2²)ˣ = 2²ˣ) para igualá-las.

## Tópicos-Chave para Revisão

<div className="topico">

**Potência** é multiplicação repetida: aⁿ = a base, n expoente, quantas vezes a base se repete. **a⁰ = 1** (qualquer base não-nula) e **a¹ = a** são casos especiais que decorrem da lógica das propriedades operatórias.

**Expoente negativo** inverte a base em fração: a⁻ⁿ = 1/aⁿ. O sinal negativo não torna o número negativo, apenas manda ele para o denominador.

**Multiplicação de mesma base**: soma expoentes (aᵐ × aⁿ = aᵐ⁺ⁿ). **Divisão de mesma base**: subtrai expoentes (aᵐ ÷ aⁿ = aᵐ⁻ⁿ). **Potência de potência**: multiplica expoentes ((aᵐ)ⁿ = aᵐˣⁿ). São as três propriedades mais cobradas.

**Distributividade do expoente** funciona em multiplicação e divisão dentro dos parênteses ((a×b)ⁿ = aⁿ×bⁿ e (a/b)ⁿ = aⁿ/bⁿ) mas NUNCA em soma ou subtração: (a+b)ⁿ ≠ aⁿ+bⁿ.

**Radiciação** é a operação inversa da potenciação: ⁿ√a tem índice n e radicando a. Sem índice escrito, é raiz quadrada (índice 2).

**Conversão raiz-potência** é a chave para resolver questões complexas: ⁿ√aᵐ = a^(m/n). Isso permite usar todas as propriedades de potência em expressões radicais.

**Racionalização** elimina raízes do denominador multiplicando numerador e denominador pela mesma raiz, sem alterar o valor da fração (multiplicar por algo/algo = multiplicar por 1).

**Sinal e expoente**: −aⁿ (menos fora dos parênteses, ou seja, fora da base) mantém o resultado negativo se n for aplicado só ao número positivo; (−a)ⁿ (menos dentro dos parênteses, incluído na base) pode virar positivo se n for par. Distinção clássica de pegadinha.
